## What counts as a second leg here

A **slide-heavy conference talk with a live product demo**, so there are two kinds of second leg, and
they are not equally strong:

- **Slides vs narration** - the usual pairing. The deck is dense and closely narrated, so most
  mechanism claims gate cleanly. This proves the speaker said what the slide says. It proves nothing
  about the world.
- **The live demo (`frame_1030`, `frame_1188`) is the better evidence in this source.** A running
  console showing a `precondition content_sha256` field, a `v1..v6 head` version strip, and one
  agent's note being consumed by another agent one minute later is a **photograph of the artifact**,
  not a restatement of the pitch. Where the demo and the slides agree, confidence is genuinely
  higher - and in two places (`n6`, `n20`) the demo carries detail the narration never states.

**Nothing here is externally corroborated, and the evidence class matters enormously in this source.**
This is a **T2 vendor talk about the vendor's own product**, at the vendor's own conference.
**Split it in two when reading:**

| Class | Nodes | How to weigh |
|---|---|---|
| **Mechanism** - how the system is built | `n1`-`n12`, `n14`-`n16`, `n19`-`n22` | The transferable part. Slides + demo agree; the design rationale stands on its own logic and can be adopted without trusting the vendor. |
| **Outcome** - how well it works | `n4`, `n17`, `n18` | **Vendor-selected customer quotes with no methodology, no baseline definition, and no published benchmark.** Internally corroborated (the slide says what the speaker says) and evidentially near-worthless. Never cite these as measured results. |

## The question this source was supposed to settle, and does not

[`../../brain/topics/memory.md`](../../brain/topics/memory.md) names one headline open question,
inherited from claim 24: **naive episodic append-and-retrieve memory hurt agent long-horizon
reliability on 6 of 10 models (T3 preprint, measured), while S6's maintained-synthesis numbers come
from a chat assistant.** Nobody has measured whether a *maintained* memory helps an *agent*.

**This source sits on exactly that side of the line and still does not close it.**

| | What would close it | What S7 supplies |
|---|---|---|
| System class | An agent loop on long-horizon tasks | **Yes** - agent platform, multi-agent, long-horizon (`n5`, `n15`, `n23`) |
| Memory design | Maintained / synthesized, not append-only | **Yes** - explicitly maintained by an out-of-band curator (`n11`, `n12`, `n14`) |
| Measurement | A disclosed method on a stated eval set | **No** - three customer testimonials on a marketing slide (`n17`, `n18`) |

The design half is answered convincingly; the evidence half is not answered at all. **Recording the
gap as still-open is the honest outcome**, and it is more useful than borrowing `n17`/`n18` to
declare it closed - a 97% or 6x figure with no baseline, no n and no eval set cannot refute a
10-model preprint.

## What this source contributes that S6 could not

- **A second, independent org converges on the same architecture** - a background process, on its own
  clock, that curates what a session wrote. Different organisation, different commercial interest,
  different system class. **Both even chose the same name, independently.** This is the strongest
  cross-source signal in the pair and the basis for `memory` reaching `established`.
- **The multi-agent case a consumer assistant has no reason to solve**: scopes (`n5`), write
  arbitration (`n6`), attribution (`n7`), and cross-agent pattern detection as the *stated reason*
  for decoupling (`n12`).
- **Memory as a tool-accessible file system** (`n2`, `n3`) - one of the two things `memory.md`
  explicitly recorded as unreachable from the consumer framing. Closed.
- **A concrete mechanism where S6 gave only an affordance**: `content_sha256` write preconditions and
  a version strip visible in a running console (`n6`, `n7`, `n20`).
- **The independence caveat, stated plainly:** convergence on *architecture* is meaningful. It is
  **not** external corroboration that the architecture *works*. Two vendors agreeing about their own
  products are two positions that happen to rhyme, and neither publishes a reproducible measurement.
