# Knowledge nodes - How DoorDash Built a Centralized Gateway for AI Agent-Tool Access (S29)

> Persona: **fact-checker** - re-adopt when working this file.

> The atomic units of knowledge extracted from this source. Stable IDs - never renumber.
> Only `corroborated` / `single-leg` nodes and recorded `divergence` findings feed `LEARNING.md`.

**Citation shorthand for this source.** The article is one page with named section headings, so the
text leg is cited `§<heading>`. The visual leg is a figure file plus the element of that figure being
leaned on. The URL is in [`SOURCE.md`](SOURCE.md).

**A note on what counts as two legs here, because this source makes it tempting to cheat.** The
article contains a table (Table 1, the four auth modes) and several bulleted lists that restate
nearby prose. **A table restating the paragraph above it is one leg, not two** - it is the same
author saying the same thing in a different shape, and counting it twice would manufacture
corroboration out of layout. Only the three drawn figures are treated as a second leg, and only where
the figure carries content rather than decoration.
