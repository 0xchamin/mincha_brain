# Knowledge nodes - Hermes Agent Architecture Part 1

> Persona: **fact-checker** - re-adopt when working this file.

> Each node has a **stable ID** (`n1`, `n2`, ... - never renumber), a claim, **both legs each with
> its own citation** (or one leg marked `single-leg`), a gate verdict, and a confidence.

> **The independence note, and it runs the good way for once.** Hermes Agent is
> [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent), an open-source project
> released in February 2026. The author writes an independent newsletter, the article reads as
> third-party analysis throughout ("What I would steal"), and **no affiliation with Nous Research is
> disclosed and none was found**. So this is a practitioner reading somebody else's public code -
> which removes the commercial position that weakens most T4 architecture writing here, and replaces
> it with a different exposure: **the author's accuracy is not independently checked by this brain**,
> because the repository was not cloned and no line was read (see `d3`).

> **What "corroborated" means for this source, stated precisely.** The two legs are the article's
> prose and the article's own four figures. Both were produced by one author in one sitting, so a
> `corroborated` verdict here proves the article is **internally consistent** - it never proves
> Hermes behaves this way. That ceiling is the ordinary one for a single-author source, and it binds
> harder than usual because **the second leg is a diagram the same author drew of the same system**.
> The reason to run the gate anyway is `d1` and `d2`: it caught two places where the figures and the
> prose say materially different things.
